Assignment 1: 
Descriptive Statistics and Central Tendency
This section involved calculating key statistical measures such as mean, median, and mode for datasets like bike prices and exam scores. It explored how outliers influence the mean more than the median, making the latter a better indicator of central tendency in skewed data. Histogram shapes were analyzed to understand skewness and its impact on statistical averages. Frequency distributions and modal values were computed for categorical variables. The distinction between sample statistics and population parameters was clarified with practical examples. Data distributions were visualized using histograms, boxplots, and bar charts to support the analysis.

Assignment 2:
Probability and Venn Diagrams
Conditional probability problems were solved using standard formulas and Bayes' theorem, including scenarios involving marbles and medical test results. Posterior probabilities were calculated to reflect updated beliefs after new evidence. Venn diagrams were used to analyze set relationships and compute probabilities for mutually exclusive and overlapping events. Each solution included step-by-step mathematical reasoning and formula-based explanations.

Assignment 3: Exploratory Data Analysis (EDA) Using Python
Using the "tips" dataset, this assignment demonstrated a complete EDA workflow in Python. The dataset was loaded and inspected using pandas, followed by data cleaning steps such as handling missing values and removing duplicates. Outliers were detected and treated using the Interquartile Range (IQR) method. Univariate analysis included calculating mean, median, trimmed mean, range, variance, and standard deviation for numerical columns. Categorical columns were analyzed through frequency counts and mode identification. Visualizations included histograms, KDE plots, boxplots, and bar charts. Bivariate relationships were explored using scatter plots and grouped boxplots, while a correlation matrix heatmap highlighted relationships among numerical variables. The assignment concluded with a summary of key insights drawn from the analysis.
